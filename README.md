# ?? AttendX - College Student Attendance Management System

**AttendX** is a full-stack college attendance management portal supporting 4 distinct roles:
1. **Students**: Attendance overview, subject-wise progress, timetable, absence warning alerts.
2. **Faculty**: Class roster, quick marking, automated shortage warnings, low-attendance lists.
3. **Principals**: Institutional analytics, departmental compliance, global notice broadcasts.
4. **Parents**: Real-time ward monitoring, automated absence intimations, advisor communication.

---

## ?? Live Demo & Deployment
- **Frontend**: React 19 + Vite 8 + React Router 7 + Lucide Icons + Axios
- **Backend**: Django REST Framework + SQLite / MySQL support
- **Automated Notifications**: Instant trigger for absence & attendance < 75%
